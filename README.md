# React Authentication Client

This React project is the frontend for the CSX4107 Authentication assignment. It calls the Next.js login and logout routes with credentials and visibly shows the `csx4107_auth` cookie. Demo login: `student@csx4107.local` / `nextjs3`.

## Run locally

1. Start the Next.js backend on port 3000.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:5173`.
